Hiredly’s Resume Builder (w. User Profile Redesign)Hiredly 的履歷產生器(含個人檔案重新設計)

Helping jobseekers create a professional resume from their profile, so they can start applying right away.幫助求職者透過個人檔案建立專業履歷,立即開始申請職缺。

About the Company關於公司

Hiredly (previously known as WOBB) is the leading hybrid recruitment platform for junior to mid-management talent. Consisting of both a job portal and a headhunting recruitment solution, it’s a discovery platform that helps people discover any job with any employer in the market.

Hiredly(前身為 WOBB)是專為初階至中階管理人才打造的領先混合型招聘平台。結合求職網站與獵頭招聘服務,是一個幫助求職者發掘市場上各種雇主與職缺的探索平台。

Project Brief專案簡介

To design a Resume Builder to allow users to easily create a professional-looking resume so they can start their job application journey. To accompany this feature, a redesign of the User Profile is also required to allow users to fill in more information about their work experiences, education, skills and so on, which can then be translated into the creation of their resume.

設計一款履歷產生器,讓使用者能輕鬆建立專業美觀的履歷,展開求職之旅。為了配合這項功能,個人檔案也需要重新設計,讓使用者能填寫更多工作經歷、學歷、技能等資訊,並將這些資訊轉化為履歷內容。

Challenges挑戰

  1. Many jobseekers are discouraged by the need to provide a resume to apply for jobs. Often, this is because they either have not created their own resumes, or the resumes uploaded were not approved; hence, this negatively affects the job application rate.
  2. The current user profile only allows users to include limited information, which is insufficient to create a resume for job applications.
  1. 許多求職者因為申請職缺需要提供履歷而卻步。這通常是因為他們還沒有自己的履歷,或是上傳的履歷未獲通過,進而影響了求職申請率。
  2. 現有的個人檔案僅能填寫有限的資訊,不足以用來建立求職所需的履歷。

Objectives目標

  1. To close the gap between users uploading their resumes and their job application journey by creating a resume with their provided information. Users can then start applying for jobs right after.
  2. To collect more relevant user information via the User Profile to support the Resume Builder feature.
  1. 透過使用者提供的資訊建立履歷,縮短使用者上傳履歷與展開求職之間的落差,讓使用者能在建立履歷後立即開始申請職缺。
  2. 透過個人檔案收集更多相關的使用者資訊,以支援履歷產生器功能。

The Process執行過程

Starting with the User Profile從個人檔案開始

Creating a resume requires more relevant information from the candidate. Hence, the project started off with increasing the sections and user fields for users to fill in. With increased fields, there was also a need to revisit the UI of the user profile to help users identify sections and entries more easily.

建立履歷需要求職者提供更多相關資訊,因此專案一開始便著手增加使用者可填寫的區塊與欄位。隨著欄位增加,個人檔案的介面也需要重新檢視,幫助使用者更容易辨識各個區塊與項目。

Research研究

To determine what is required to create a good resume, whilst catering to the needs of both fresh grads and experienced jobseekers.

確認打造一份好履歷所需的要素,同時兼顧應屆畢業生與有經驗求職者的需求。

Final Mockup最終視覺稿

Resume Template履歷範本

With the User Profile design ready, the entry fields available there are then incorporated into a resume template. This template is used to reflect the information provided by the user on the User Profile when they use the Resume Builder to create their resume.

個人檔案設計完成後,其中的欄位內容便會被納入履歷範本中。使用者透過履歷產生器建立履歷時,這份範本會呈現他們在個人檔案中填寫的資訊。
